About SecurePass

How it works

Your master password and domain name are combined using PBKDF2 with 100,000 iterations to generate a unique, deterministic password. The same inputs always produce the same output — so you never need to store your passwords anywhere.

Security

  • Zero data collection — no servers, no tracking
  • Offline-first — works without an internet connection
  • All processing happens in your browser via the Web Crypto API
  • 256-bit cryptographic operations
  • Auto-locks after 5 minutes of inactivity

Features

  • Deterministic generation — same input always yields the same password
  • Domain history with smart categorization
  • PIN and biometric protection
  • PWA support — install as a native-like app
  • Integrated breach checking
